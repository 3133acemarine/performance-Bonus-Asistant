# 성과상여금 도우미 (PWA)

부대(서)별 엑셀을 모아 자동 점검하고, 부대 × 계급 그룹별 등급·지급액을 산정한 뒤
개인별 **산정근거표(생년월일 암호 PDF)** 와 **보고용 엑셀**을 만드는 웹앱입니다.
PRD v1.1(`성과상여금_산정도구_PRD_1.md`) 기준으로 만들었습니다.

- 서버는 파일만 내려주는 정적 웹서버입니다. 로그인·DB·업로드 없음.
- 엑셀·결과 자료는 브라우저 메모리에서만 처리하며 어디에도 저장·전송하지 않습니다.
- 인터넷 불필요: 라이브러리(SheetJS, jsPDF, JSZip)와 한글 폰트(나눔고딕)가 `index.html` 안에 들어 있습니다.

## 실행 방법

### 방법 1. 로컬 서버로 실행 (권장 · 설치/오프라인 가능)
1. 이 폴더의 **`실행.bat`** 을 더블클릭합니다.
2. 브라우저가 `http://localhost:8080/` 으로 열립니다. (크롬 또는 엣지)
3. 주소창 오른쪽의 **앱 설치 아이콘**(또는 첫 화면의 [앱 설치] 버튼)을 누르면 바탕화면·작업표시줄 아이콘이 생깁니다.
   한 번 설치하면 서버를 꺼도 아이콘으로 실행됩니다(오프라인).
4. 끝낼 때는 검은 서버 창을 닫습니다.

터미널에서 직접 실행하려면:

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

포트가 이미 쓰이고 있으면 `-Port 8081` 처럼 바꿉니다.

### 방법 2. 파일 직접 열기 (예비 방식)
`dist\index.html` 을 크롬·엣지로 직접 엽니다. 설치·오프라인 캐시·새 버전 알림만 빠지고 기능은 같습니다.
화면 하단에 "설치 없이 실행 중"으로 표시됩니다.

## 사용해 보기 (가상 샘플 자료)
`samples\` 폴더에 가상 자료가 있습니다(실제 인물 아님, 내용은 `samples\읽어보기.txt`).
첫 화면의 [가상 샘플 자료 받기] 버튼으로도 같은 ZIP을 받을 수 있습니다.

1. **본부 담당자** 선택 → `samples\1_오류포함_원본` 의 엑셀 21개를 끌어다 놓기 → 오류(E01~E06)·경고(W01~W05) 확인
2. [모든 파일 빼기] → `samples\2_오류수정본` 21개를 넣기 → 경고 확인 체크 → 다음
3. 기준 설정에서 계급별 기준액 입력(테스트용 [빈 칸에 예시 금액 넣기] 버튼 있음) → 산정하기
4. 산정 결과 화면에서 [작년 결과 엑셀 불러오기] → `samples\3_작년결과` 파일 → 등급 변화 확인
5. 내보내기에서 보고용 엑셀, 산정근거표 PDF ZIP 내려받기 (PDF 암호 = 각자 생년월일 6자리)

**부대 담당자**는 자기 부대 명단 + 평가결과 엑셀을 넣고 점검한 뒤 [표준 양식 엑셀 저장]으로 본부에 제출합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `dist\` | **배포용 완성본.** 이 폴더 전체(`index.html`, `sw.js`, `manifest.webmanifest`, `icons\`)를 내부망 HTTPS 정적 웹서버에 올리면 됩니다 |
| `src\` | 원본 코드 (`app.js` 앱 로직, `samples.js` 샘플 생성기, `style.css`, `sw.js`, `manifest.webmanifest`, `index.template.html`) |
| `vendor\` | 내장 라이브러리와 한글 폰트 (SheetJS 0.20.3, jsPDF 2.5.2, JSZip 3.10.1, 나눔고딕 OFL) |
| `build.ps1` | `src` + `vendor` → `dist` 빌드 (라이브러리·폰트를 index.html 에 넣고 아이콘 생성) |
| `serve.ps1` | 설치 없이 쓰는 로컬 정적 웹서버 (Windows PowerShell 기본 기능만 사용) |
| `실행.bat` | 더블클릭 실행용 (dist 가 없으면 빌드 후 서버 실행) |
| `VERSION` | 앱 버전. 화면 하단과 서비스 워커 캐시 이름에 같은 값이 들어갑니다 |
| `samples\` | 가상 샘플 엑셀 (오류포함본 21개, 수정본 21개, 작년 결과 1개) |

## 수정·새 버전 배포
1. `src\` 를 고친 뒤 `VERSION` 숫자를 올립니다 (예: 1.0.0 → 1.0.1).
2. 빌드합니다.

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

3. 서버의 파일을 새 `dist\` 로 바꿉니다. 사용자가 앱을 열면 "새 버전이 있습니다. 새로고침" 안내가 뜨고,
   누르면 새 버전으로 바뀝니다(작업 중 자동 새로고침 없음).

## Vercel 배포
`vercel.json` 이 빌드 없이 `dist\` 폴더를 그대로 서비스하도록 설정되어 있습니다(HTTPS 자동).
`main` 에 푸시하면 자동으로 다시 배포됩니다. 소스를 고쳤다면 `build.ps1` 로 `dist\` 를 다시 만든 뒤 커밋하세요.
주소: https://performance-bonus-asistant.vercel.app/

## 참고
- 기본 기준값(등급 비율 S20/A40/B30/C10, 지급률 172.5/125/85/0%, 지급 제외 2개월 미만)은 **예시**입니다. 실제 사용 전 해당 연도 지침과 대조하세요.
- "2개월"은 기본이 "근무 시작일 기준 만 2개월(달력)"이며, 기준 설정에서 "일수 환산"으로 바꿀 수 있습니다.
- PDF 암호는 jsPDF가 지원하는 RC4 방식이며 생년월일은 추측하기 쉬운 암호입니다(PRD R1·R5).
- 내부망에 올릴 때는 HTTPS가 필요합니다. `localhost` 는 HTTPS 없이도 설치·오프라인이 됩니다.
